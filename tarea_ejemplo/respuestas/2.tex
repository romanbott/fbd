Las principales diferencias entre PostgreSQL y otros SMBD:

\begin{itemize}
    \item \textbf{vs MySQL/MariaDB:} PostgreSQL soporta tipos de datos avanzados (JSONB, arrays, geoespaciales), herencia de tablas, MVCC más robusto, y cumplimiento estricto de ACID.
    \item \textbf{vs Oracle:} PostgreSQL es open source sin costos de licencia, arquitectura más simple, pero Oracle tiene mejor particionamiento nativo y herramientas enterprise.
    \item \textbf{vs SQL Server:} PostgreSQL es multiplataforma nativo, mejor soporte para extensiones, mientras SQL Server integra mejor con ecosistema Microsoft.
    \item \textbf{vs NoSQL:} PostgreSQL garantiza consistencia fuerte (ACID), transacciones complejas, y SQL estándar; NoSQL prioriza escalabilidad horizontal y flexibilidad de esquema.
\end{itemize}
