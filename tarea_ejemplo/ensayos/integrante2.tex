\section*{Arquitecturas híbridas: SQL y NoSQL en convivencia}

Las aplicaciones modernas rara vez se ajustan a un solo modelo de datos. Este ensayo explora patrones de arquitectura políglota donde PostgreSQL (relacional) convive con MongoDB (documentos) y Redis (clave-valor), analizando estrategias de sincronización, consistencia y particionamiento de responsabilidades.
