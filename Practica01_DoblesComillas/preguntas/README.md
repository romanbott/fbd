# Plantilla para tareas - UNAM FCiencias.


Es necesario editar las variables:

- `\documentoTitulo`
- `\documentoSubtitulo`
- `\integranteUno`
- `\integranteDos`
- `\integranteTres`
- `\integranteCuatro`


# Para compilar

Dependiendo de lo que se tenga instalado se puede usar cualquiera de los siguientes comandos:
```pdflatex tarea1.tex```

```tectonic -X compile tarea1.tex```

```xelatex tarea1.tex```
