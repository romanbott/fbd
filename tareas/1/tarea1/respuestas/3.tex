\item
Una empresa debería escoger una base de datos open source por:

\begin{itemize}
	\item \textbf{Costo total de propiedad (TCO) menor:} Sin licencias por núcleo/usuario, libertad de escalar horizontalmente sin costos adicionales.
	\item \textbf{Independencia del proveedor (vendor lock-in):} Código abierto permite migración, auditoría y personalización sin depender de un vendor.
	\item \textbf{Comunidad y ecosistema:} Miles de contribuyentes, extensiones, conectores, y documentación abundante.
	\item \textbf{Seguridad y transparencia:} Código auditable, parches de seguridad rápidos, sin backdoors ocultos.
	\item \textbf{Flexibilidad tecnológica:} Corre en cualquier OS, nube, contenedor, o bare metal sin restricciones contractuales.
\end{itemize}
