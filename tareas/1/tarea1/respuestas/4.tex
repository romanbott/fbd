\item
Ventajas para un DBA trabajando con SMBD open source:

\begin{itemize}
	\item \textbf{Control total del motor:} Acceso al código fuente para debugging profundo, optimización de consultas a nivel interno, y parches personalizados.
	\item \textbf{Herramientas de monitoreo gratuitas:} pg\_stat\_statements, pg\_badger, pg\_center, Prometheus/Grafana exporters sin licencias extra.
	\item \textbf{Extensibilidad:} Crear funciones, tipos, operadores, y extensiones (PostGIS, TimescaleDB, Citus) sin esperar al vendor.
	\item \textbf{Comunidad de soporte:} Mailing lists, Stack Overflow, conferencias (PGConf, PostgresOpen) con expertos accesibles.
	\item \textbf{Portabilidad de habilidades:} Conocimiento transferible entre PostgreSQL, MySQL, MariaDB, y forks.
	\item \textbf{Automatización DevOps:} Ansible, Terraform, Operators de Kubernetes nativos para PostgreSQL (CloudNativePG, Zalando).
\end{itemize}
