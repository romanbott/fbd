\item Durante el desarrollo de un nuevo sistema empresarial surge una discusión entre quienes consideran que la base de datos debe diseñarse pensando únicamente en las necesidades actuales y quienes proponen anticipar futuros requerimientos. Analiza esta situación relacionándola con el ciclo de vida de una base de datos y argumenta cómo las decisiones tomadas durante las etapas iniciales pueden influir en el mantenimiento, evolución y costo del sistema a largo plazo.
