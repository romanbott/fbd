Los principales SMBD (Sistemas Manejadores de Bases de Datos) en el mercado actual son:

\begin{itemize}
	\item \textbf{Comerciales:} Oracle Database, Microsoft SQL Server, IBM Db2, SAP HANA
	\item \textbf{Open Source:} MySQL, MariaDB, PostgreSQL, SQLite, Firebird
	\item \textbf{NoSQL:} MongoDB, Redis, Cassandra, Couchbase, DynamoDB, Neo4j
	\item \textbf{En la nube:} Amazon Aurora, Google Cloud Spanner, Azure Cosmos DB
\end{itemize}
